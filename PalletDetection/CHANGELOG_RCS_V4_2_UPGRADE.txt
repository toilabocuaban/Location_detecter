2. ĐẶC TẢ GIAO TIẾP RCS-2000 V4.2.0 ĐÃ TRIỂN KHAI:
- URL mặc định:
  POST https://192.168.65.193/rcs/rtas/api/robot/controller/task/submit
  (hỗ trợ chỉnh trực tiếp URL, Task Type, Robot Code, Pick-up, Drop-off trên tab Cấu hình).
- HTTP Headers:
  + X-lr-request-id: 16 ký tự hex duy nhất theo mỗi lần gọi Apply Task (RcsV4ApiClient).
  + X-lr-version: v1.0
  + X-lr-trace-id: 32 ký tự hex
  + X-lr-source: ClientCode từ rcs_config.json (mặc định VISION_PALLET_APP)
  + Content-Type: application/json; charset=utf-8
  + Đã bật TLS 1.2 (ServicePointManager.SecurityProtocol |= SecurityProtocolType.Tls12) cho https://.
- JSON Request Body:
  + Khi có Robot Code (mặc định "19781", hỗ trợ nhiều mã cách nhau dấu phẩy ','):
    {
      "taskType": "QF2",
      "targetRoute": [
        { "seq": 0, "type": "SITE", "code": "<PickupPosition>" },
        { "seq": 1, "type": "SITE", "code": "<DropoffPosition>" }
      ],
      "robotType": "ROBOTS",
      "robotCode": ["19781"]
    }
  + Khi xóa trống ô Robot Code: không gửi 2 trường "robotType" và "robotCode" để RCS-2000
    tự động chọn xe AMR rảnh tối ưu theo tài liệu mục 2.1.2.
- Xử lý Response:
  + Thành công khi HTTP 200 và JSON code == "SUCCESS"; trích mã task từ data.robotTaskCode.
  + Đối chiếu header X-lr-request-id trả về từ RCS.
  + Vẫn giữ nguyên 6 phân loại kết quả (Success, BusinessError, HttpError, NetworkError,
    Timeout, JsonParseError) và KHÔNG tự động retry khi lỗi/timeout để tránh tạo trùng task.
- Tương thích ngược rcs_config.json cũ:
  + RcsApiConfig.LoadOrCreateDefault() tự động nâng cấp endpointPath V3.3 cũ sang
    /rcs/rtas/api/robot/controller/task/submit và bổ sung mặc định taskType="QF2",
    robotCode="19781" nếu file cũ chưa có.
